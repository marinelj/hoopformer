MULTICLASS SOFTMAX REGRESSION

Softmax 回归从分数到梯度下降

先看核心公式；点开每一步，再看它为什么成立。

Z→ P→ L→ J→ D→ ∇J→ 更新
先查符号与形状 (n, d, K)

n 个样本，d 个特征，K 个类别。每一行是一个样本；本页按完整训练集做 full-batch gradient descent。

符号形状含义
X(n, d)特征矩阵；第 i 行为一个样本。
W(d, K)权重矩阵；每一列对应一个类别。
b(1, K)偏置；向每一行广播。
Z(n, K)原始分数，logits。
P(n, K)预测概率；每行之和为 1。
Y(n, K)one-hot 标签；真实类别为 1，其余为 0。

i 是样本索引；j、k 是类别索引；a 是特征索引。推导某个样本时，c 表示它的真实类别。所有索引从 1 开始。

ℓᵢ：单样本损失；L：平均数据损失；J：加正则后的目标，三者都是标量。log 为自然对数；Σᵢ 遍历样本，Σⱼ / Σₖ 遍历类别。

C > 0 控制正则强度；η > 0 是学习率。∇ 表示梯度，∂ 表示偏导，⊤ 表示转置。

01

线性分数 LOGITS

Z = XW + b
(n, d) · (d, K) → (n, K)

每个样本，对每个类别计算一个分数。

展开详细推导收起详细推导

把矩阵乘法展开到一个元素

Zik = Σₐ XiaWak + bk
a = 1, …, d。同一个类别的权重列与样本特征做点积。

例如有两个特征、三个类别，样本 xᵢ = [2, 3]，第 2 类的权重向量为 [0.5, −1]，偏置为 b₂ = 0.2：

Zi2 = 2 × 0.5 + 3 × (−1) + 0.2
　　 = −1.8

这个分数可以为负，也不要求所有类别分数之和为 1。下一步用 softmax 把一行分数转换成概率。

b 的形状是 (1, K)，广播到 n 行；等价于 Z = XW + 1ₙb，其中 1ₙ 是形状为 (n, 1) 的全 1 列向量。
02

分数变概率 SOFTMAX

Pik = exp(Zik)Σⱼ exp(Zij)
P: (n, K) · 沿类别方向计算

一行是一组概率：每个值大于 0，行和为 1。

展开定义与例子收起定义与例子

先取指数，再按行归一化

固定样本 i。令 Sᵢ = Σⱼ exp(Zᵢⱼ)，它是这一行所有指数值的总和。

Zᵢ = [0, log 2, 0]
exp(Zᵢ) = [1, 2, 1]
Sᵢ = 1 + 2 + 1 = 4
Pᵢ = [0.25, 0.50, 0.25]

因为每项 exp(Zᵢₖ) > 0，而分母是它们的总和，所以 Σₖ Pᵢₖ = Sᵢ / Sᵢ = 1。

softmax 在每个样本内部、沿 K 个类别归一化。它不会跨 n 个样本做归一化，因此这里没有 / n。

实际计算：减去行最大值

令 mᵢ = maxⱼ Zᵢⱼ，使用完全等价的稳定写法：

Pik = exp(Zik − mᵢ)Σⱼ exp(Zij − mᵢ)

分子和分母都乘了同一个 exp(−mᵢ)，比例不变，同时避免大正数取指数导致溢出。

03

交叉熵损失 CROSS-ENTROPY LOSS

ℓᵢ = −Σₖ Yik log Pik
L = 1n Σᵢ ℓᵢ
ℓᵢ、L 都是标量

先算每个样本的损失，再对样本取平均。

展开：从概率改写为 Z收起详细推导

one-hot 只选中真实类别

对当前样本，真实类别是 c：Yic = 1，其余位置为 0。于是：

ℓᵢ = −log Pic
真实类别的概率越大，负对数损失越小。

代入 softmax

Pic = exp(Zic) / Sᵢ
ℓᵢ = −log[exp(Zic) / Sᵢ]
用 log(a / b) = log a − log b。
　 = −[Zic − log Sᵢ]
　 = −Zic + log Sᵢ
　 = −Zic + log Σⱼ exp(Zij)
接下来只需对两项求导：−Zic 产生 −Yᵢₖ，log Σⱼ exp(Zᵢⱼ) 产生 Pᵢₖ。

平均损失从哪里开始出现？

L = (ℓ₁ + ℓ₂ + … + ℓₙ) / n

这里第一次引入 1 / n。它是平均操作的系数，求导时作为常数保留下来。若定义的是损失总和，就没有这个系数。

上面的概率例子中，若 c = 2，则 ℓᵢ = −log 0.5 ≈ 0.6931。实际计算可直接用稳定写法 ℓᵢ = −Zic + mᵢ + log Σⱼ exp(Zᵢⱼ − mᵢ)，避免先算极小概率再取对数。

04

加上 L2 正则 REGULARIZED OBJECTIVE

J = L + ‖W‖F22Cn
J 是最终要最小化的标量

拟合数据，同时约束权重大小；偏置不正则化。

展开：L2 为什么得到 W / (Cn)收起 L2 推导

先把平方范数展开

‖W‖²F 是 Frobenius norm 的平方，即所有权重元素的平方和：

‖W‖F2 = Σₐ Σₖ Wak2
R(W) = 12Cn Σₐ Σₖ Wak2

对其中一个权重求导

只有 Wₐₖ² 这一项与当前求导的 Wₐₖ 有关，其他权重的平方项都是常数。

∂R / ∂Wak
= 12Cn × 2Wak
因为 d(w²) / dw = 2w，系数中的 2 被抵消。
= Wak / (Cn)

每个元素都成立，组合成同形状的矩阵：

∇WR = W / (Cn)
形状为 (d, K)。由于 R 不含 b，所以 ∇bR = 0。
C 越大，正则越弱。本页固定采用 R = ‖W‖²F / (2Cn)；若写成 R = λ‖W‖²F / 2，对应 λ = 1 / (Cn)。
这里的 n 是完整目标中的训练样本数。若改成 minibatch，数据损失按 batch 大小 B 取平均；正则系数仍应与原目标一致，不能直接把正则分母中的 n 也替换成 B。
05

对分数求梯度 GRADIENT WITH RESPECT TO Z

D ≡ ∂L∂Z = P − Yn
D: (n, K)

P − Y 来自求导；/ n 来自平均。

展开：逐项推导 P − Y 与 / n收起详细推导

① 第一项：为什么只有真实类别得到 −1？

固定一个样本 i，从上一节的等式出发：

ℓᵢ = −Zic + log Sᵢ
Sᵢ = Σⱼ exp(Zij)

对第 k 个 logit 求偏导：

∂(−Zic) / ∂Zik
= −1　当 k = c
=　0　当 k ≠ c
k = c 时是 d(−x) / dx = −1；k ≠ c 时该变量没有出现在这一项中，导数为 0。
= −Yik

② 第二项：log-sum-exp 的导数

先用链式法则（chain rule）：外层对数的导数是 1 / Sᵢ，再乘内层的导数。

∂ log Sᵢ∂Zik = 1Sᵢ · ∂Sᵢ∂Zik

将内层总和展开，只有第 k 项与 Zᵢₖ 有关：

Sᵢ = exp(Zi1) + …
　　 + exp(Zik) + …
∂Sᵢ / ∂Zik = exp(Zik)
其他项导数为 0；而 d(exp x) / dx = exp x。

代回链式法则，恰好就是 softmax 概率：

∂ log Sᵢ / ∂Zik
= exp(Zik) / Sᵢ
= Pik

③ 合并两项，得到 P − Y

∂ℓᵢ / ∂Zik
= −Yik + Pik
= Pik − Yik

把该样本所有类别排成一行：∂ℓᵢ / ∂Zᵢ = Pᵢ − Yᵢ。这还是单样本损失的梯度，没有 / n。

④ 对平均损失求导，得到 / n

L = (1 / n) Σᵣ ℓᵣ
∂L / ∂Zik
= (1 / n) Σᵣ ∂ℓᵣ / ∂Zik
1 / n 是常数。这里用 r 遍历样本，避免与固定的 i 混淆。
= (1 / n) ∂ℓᵢ / ∂Zik
r ≠ i 时，ℓᵣ 不依赖第 i 行的分数，所以对应偏导为 0。
= (Pik − Yik) / n
把所有位置排回矩阵：D = (P − Y) / n。P − Y 来自 softmax 与交叉熵的组合求导；/ n 只来自 loss 的 mean reduction。

用一行数字核对

固定 Pᵢ = [0.25, 0.50, 0.25]。切换真实类别，观察哪个位置减去 1；切换样本数，观察平均系数。

Yᵢ[0, 1, 0]
Pᵢ − Yᵢ[0.25, −0.5, 0.25]
Dᵢ[0.0625, −0.125, 0.0625]

真实类别的梯度为负，其余类别为正。若直接更新这行 logits，减去梯度会提高真实类别分数、降低其余分数。

这里只展示平均损失对其中一行 logits 的偏导；n > 1 时，其他样本的行没有列出。实际训练通过 W、b 更新，最终方向还受其他样本与正则项影响。

另一路推导：softmax Jacobian × 交叉熵

若从 P 直接套链式法则，需要考虑每个概率与所有 logits 的关系。令 δⱼₖ 为 Kronecker delta：j = k 时为 1，否则为 0。

∂Pij / ∂Zik
= Pij(δjk − Pik)
∂ℓᵢ / ∂Pij = −Yij / Pij

softmax 的导数来自商法则：

∂Pij / ∂Zik
= [δjk exp(Zij) Sᵢ
　 − exp(Zij) exp(Zik)]
　 / Sᵢ²
= Pijδjk − PijPik

然后对所有中间概率求和：

∂ℓᵢ / ∂Zik
= Σⱼ (−Yij / Pij)
　 × Pij(δjk − Pik)
= −Σⱼ Yijδjk + PikΣⱼ Yij
= −Yik + Pik
因为 Σⱼ Yᵢⱼ = 1。这是目标分布归一化的条件；本页使用 one-hot 标签。

不要再把已经得到的 P − Y 额外乘一次 softmax 导数；这里已经完成了整个组合的链式求导。

L2 是一条从 W 直接进入 J 的支路。这里的 D 只负责 Z → P → L 路径；下一步在 W 的梯度处加上正则梯度。

06

传回权重与偏置 PARAMETER GRADIENTS

∇WJ = X⊤D + WCn
∇bJ = Σᵢ Di:
∇WJ: (d, K) · ∇bJ: (1, K)

先用链式法则回传，再加上 L2 的权重梯度。

展开：为什么是 X⊤D 与按行求和收起详细推导

① 对一个权重 Wₐₖ 求导

从 Zᵢₖ = Σₐ XᵢₐWₐₖ + bₖ 可知，∂Zᵢₖ / ∂Wₐₖ = Xᵢₐ。这个权重会影响所有样本的第 k 类分数。

∂L / ∂Wak
= Σᵢ (∂L / ∂Zik)
　 × (∂Zik / ∂Wak)
= Σᵢ DikXia

而矩阵 X⊤D 的第 (a, k) 个元素正是这项总和：

(X⊤D)ak = Σᵢ XiaDik
∇WL = X⊤D
形状检查：(d, n) · (n, K) = (d, K)，与 W 一致。

② 对偏置 bₖ 求导

每个样本的第 k 个分数都加了同一个 bₖ，因此 ∂Zᵢₖ / ∂bₖ = 1：

∂L / ∂bk
= Σᵢ Dik × 1
= Σᵢ Dik

对每一列分别加总所有样本的贡献，保留一行：

∇bL = Σᵢ Di:
代码对应 D.sum(axis=0, keepdims=True)，输出 (1, K)；Dᵢ: 表示第 i 行。

③ 加上正则梯度，得到 J 的梯度

∇WJ = ∇WL + ∇WR
　　 = X⊤D + W / (Cn)
∇bJ = ∇bL + 0
　　 = Σᵢ Di:

如果不引入中间变量 D，同样可以直接写：

∇WJ = X⊤(P − Y) / n
　　　 + W / (Cn)
∇bJ = Σᵢ (Pi: − Yi:) / n
D 已经除过 n。接着用 X⊤D 和 sum(D)，不要再除一次 n。偏置也应使用求和，避免对 D 再取一次 mean。
07

沿负梯度更新 GRADIENT DESCENT

W ← W − η∇WJ
b ← b − η∇bJ
回到第 1 步，用新参数重新计算

同一轮先算完所有梯度，再更新两个参数。

展开：更新方向与正则的作用收起详细推导

为什么要减去梯度？

梯度指向目标局部增长最快的方向。用正学习率 η 沿反方向走一小步，能在步长足够小时降低目标。

若 ∂J / ∂w = 0.3，η = 0.1：
wnew = wold − 0.03
若 ∂J / ∂w = −0.3：
wnew = wold + 0.03

将 L2 梯度代入更新式

Wnew = W − η[X⊤D + W / (Cn)]
　　 = (1 − η / (Cn))W
　　　 − ηX⊤D
bnew = b − ηΣᵢ Di:

普通梯度下降中，L2 项额外贡献 −ηW / (Cn)。当 0 < η / (Cn) < 1 时，这部分把权重按比例向 0 收缩。

右侧的 W、b、P、D 都来自同一轮的旧参数。先保存 grad_W 和 grad_b，再分别更新；下一轮重新计算 Z → P → L → J。

学习率过大会导致目标上升或震荡。观察的是正则化目标 J；降低 J 时，数据损失 L 不一定每轮都下降。

对照：一轮 NumPy 训练代码

与七步公式一一对应。Y 为 one-hot，b 为 (1, K)；此代码按完整训练集更新。

# X: (n, d), W: (d, K)
# b: (1, K), Y: (n, K)
import numpy as np

n = X.shape[0]

# 1. Logits
Z = X @ W + b

# 2. Stable softmax
A = Z - Z.max(axis=1, keepdims=True)
E = np.exp(A)
S = E.sum(axis=1, keepdims=True)
P = E / S

# 3. Mean cross-entropy
log_P = A - np.log(S)
L = -(Y * log_P).sum(axis=1).mean()

# 4. Regularized objective (C > 0)
R = (W * W).sum() / (2 * C * n)
J = L + R

# 5. Gradient through logits
D = (P - Y) / n

# 6. Both gradients use old parameters
grad_W = X.T @ D + W / (C * n)
grad_b = D.sum(axis=0, keepdims=True)

# 7. Update (eta > 0)
W = W - eta * grad_W
b = b - eta * grad_b

log_P 直接由稳定的 log-softmax 计算，避免对已经下溢到 0 的概率取 log。网页本身无需安装或运行 Python。
