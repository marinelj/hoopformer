# Softmax 回归学习页

[打开 HTML 文件](softmax-regression-study.html)，查看从 logits 到梯度下降的完整推导。页面使用简洁中文配合英文术语，适合手机阅读。

- 主页面只显示七步核心流程与关键公式；点击每一步展开详细推导，阅读后可收起并返回该步骤。
- 覆盖 `X`、`W`、`b`、`Z`、`P`、`Y` 的形状、交叉熵、平均损失、L2 正则、参数梯度与更新。
- 重点推导 `P - Y`、`/ n` 以及 `‖W‖²_F / (2Cn)` 对 `W` 的梯度 `W / (Cn)`。
- 包含可切换真实类别与样本数的数值例子，以及一轮 NumPy 训练代码对照。

## 浏览与部署

这是包含 CSS 和 JavaScript 的完整单文件 HTML。下载后用浏览器打开即可离线阅读，无需安装依赖。

在 Jupyter 中，使用 `/files/` 加文件相对于该服务根目录的路径，直接打开页面。GitHub 的文件页面显示的是 HTML 源码。部署到 Mac Studio 的完整交接提示词见 [MACSTUDIO_PROMPT.md](MACSTUDIO_PROMPT.md)。
